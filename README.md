# Amazon-Sales-Data-India
## Project Objective
The objective of the Amazon India Sales Dashboard project is to analyze Amazon sales data and convert the raw data into a clear, interactive dashboard that helps management understand sales, profit, product/category performance, order status, payment methods, fulfillment, and geographic performance.
